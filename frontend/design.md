# SkillNet Design System

## Color Palette

- **Primary Dark Blue:** `#0c2b54` (Used for Headings, logo text, primary buttons, escrow section background, and footer background)
- **Accent Mint Green:** `#4ade80` / `#6bf0a5` (Used for "THE KNOWLEDGE EXCHANGE PROTOCOL" tags, call-to-action buttons like "Join the Network")
- **Background Light Gray:** `#f8fafc` (Used for the overall page background and sections like "How SkillNet Operates")
- **Card White:** `#ffffff` (Used for feature cards, testimonial cards, and the floating stats widget)
- **Text Primary (Dark):** `#0f172a` (Used for main body text and regular headings)
- **Text Secondary (Gray):** `#64748b` (Used for descriptive paragraph text, roles in testimonials, footer links)
- **Border Regular:** `#e2e8f0` (Used for button borders, card borders)

## Typography

- **Font Family:** Inter or system sans-serif (modern, clean, geometric sans).
- Large titles with tight tracking, bold weight (`600` - `800`).
- Subtle UI text with medium weight (`500`) for tags and small buttons.
